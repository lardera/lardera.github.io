Privacy Policy – Channel Stats Reader

Last updated: November 20, 2026

What the application does

Channel Stats Reader is a private tool used by a single person: the owner of the YouTube channel it reads. It uses Google OAuth to access, in read-only mode, that channel's data through the YouTube Analytics API (scope yt-analytics.readonly) and the YouTube Data API v3 (scope youtube.readonly).

Data accessed

Only statistics and metadata of the authorizing user's own channel (for example views, watch time, subscribers and video details). No data about other people is collected.

How data is used

Data is used solely to generate private reports for the channel owner. It is not sold, shared with or transferred to third parties, and it is not used for advertising or to train AI models.

Storage and deletion

Data and OAuth tokens are stored only on the owner's own systems and can be deleted at any time. Access can be revoked at any time from myaccount.google.com/permissions.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be submitted through the issue tracker of the repository hosting this page.
